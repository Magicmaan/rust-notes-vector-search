# Data Model: Electron → Tauri Migration

## Entity: MigrationManifest
- **Fields**:
  - `sourceProjectPath` (string, absolute path)
  - `targetProjectPath` (string, absolute path; must be `../rust-notes-vector-search`)
  - `copiedDirectories` (string[])
  - `removedElectronFiles` (string[])
  - `addedTauriFiles` (string[])
  - `dependencyChanges` (object: removed[], added[])
- **Validation Rules**:
  - Target path must not be inside source repo.
  - Copied directories must include existing frontend feature directories.

## Entity: TauriRuntimeConfig
- **Fields**:
  - `bundle.identifier` (string)
  - `build.devUrl` (string)
  - `build.frontendDist` (string)
  - `build.beforeDevCommand` (string)
  - `build.beforeBuildCommand` (string)
  - `app.windows` (array)
  - `capabilities` (array)
- **Validation Rules**:
  - `devUrl` must point to active Vite dev server.
  - `frontendDist` must resolve to built frontend output.
  - Capabilities must be least-privilege.

## Entity: FrontendEntrypointContract
- **Fields**:
  - `frontendDevCommand` (string)
  - `frontendBuildCommand` (string)
  - `tauriDevCommand` (string)
  - `tauriBuildCommand` (string)
- **Validation Rules**:
  - Commands run successfully in target directory.
  - Dev startup opens Tauri window loading frontend route.

## Relationships
- `MigrationManifest` produces `TauriRuntimeConfig` and `FrontendEntrypointContract`.
- `TauriRuntimeConfig` references outputs generated by `FrontendEntrypointContract`.

## State Transitions
1. `Planned` → 2. `Scaffolded` → 3. `RuntimeSwapped` → 4. `Validated` → 5. `Packaged`
